The AI Watching the AI

How the meta-agent analyzes tool calls, finds failure patterns, and recommends optimizations — using AI itself

🔭
AgentNexus doesn't just run agents — it watches them. A dedicated endpoint collects the last 24 hours of execution data, sends it to Qwen-Max for analysis, and returns actionable insights: which tools are failing, what patterns cause latency spikes, and how to fix them.

The system is self-aware. Let's see how.

Step 1: The analytics query

A single query that joins sessions with tool calls, grouped by agent type, tool name, status, and latency.

CODE 
SELECT
    s.agent_type,
    t.tool_name,
    t.status,
    t.latency_ms,
    COUNT(*) AS cnt
FROM   agent_sessions s
JOIN   tool_call_history t ON s.session_id = t.session_id
WHERE  s.tenant_id  = %s
  AND  s.created_at > NOW() - INTERVAL 24 HOUR
GROUP BY s.agent_type, t.tool_name, t.status, t.latency_ms
PLAIN ENGLISH

For each agent type (research, codegen, data, web)...

...and each tool used (web_search, code_exec, db_query, etc.)...

...count how many calls succeeded, failed, or timed out...

...along with their latency in milliseconds.

Only for this tenant (from the verified JWT context).

Only for sessions created in the last 24 hours.

Grouped so you can spot patterns: "web_search fails 15% of the time after 22:00 UTC."

Step 2: Sending data to Qwen-Max

The raw stats are serialized to JSON and sent as a prompt to Qwen-Max via the DashScope API.

CODE 
async def _call_qwen(summary_str):
    async with httpx.AsyncClient(timeout=30) as client:
        resp = await client.post(
            "https://dashscope.aliyuncs.com/api/v1/...",
            headers={"Authorization": f"Bearer {API_KEY}"},
            json={
                "model": "qwen-max",
                "input": {"messages": [
                    {"role": "system",
                     "content": "You are an AI agent optimizer."},
                    {"role": "user",
                     "content": f"Analyze this: {summary_str}"},
                ]},
            },
        )
PLAIN ENGLISH

Create an HTTP client with a 30-second timeout.

POST to DashScope's text generation endpoint.

Authenticate with the DashScope API key.

Use the qwen-max model (a powerful LLM).

System prompt: "You are an AI agent optimizer."

User prompt: "Analyze this execution data."

The LLM reads the raw stats and returns optimization JSON.

🔄
Mock fallback: If the DashScope API key isn't set or the API is unreachable, AgentNexus returns a realistic mock analysis. This means the course works even without external API access — no broken demos.

What the meta-agent returns

The response combines raw data with AI-powered insights.

📊 raw_stats

The raw data from TiFlash — every combination of agent type, tool, status, and latency from the last 24 hours.

🔍 failure_patterns

Natural language descriptions of what's going wrong: "web_search error rate exceeds 15% after 22:00 UTC", "db_query failures correlate with context payloads > 8 KB".

⚡ tool_optimizations

Concrete, actionable fixes per tool: "Add retry with exponential back-off (max 3 attempts, base 500ms); cache identical queries for 5 min".

📈 efficiency_score

A single number (0-100) summarizing how well the agent fleet is performing. Derived from success rate, latency, and resource utilization.

🎯 top_3_recommendations

The three highest-impact changes, ranked by expected improvement: "Parallelise independent tool calls within a session to cut average latency by ~22%".

The insights endpoint — dashboards in JSON

GET /api/{tenant_id}/insights — a richer analytics endpoint with derived metrics.

📋

Session Statistics

Total sessions, completion rate, average duration, unique agent types — all scoped to the last 24 hours.

🔧

Tool Usage Patterns

Which tools are called most, their success/failure rates, and average latency. Helps identify the bottleneck tool.

📈

Agent Performance

Breakdown by agent type: how many sessions each type ran, how many completed vs failed, average duration.

📅

Daily Trend

Sessions per day for the last 7 days, split by completed/failed. Spot whether things are getting better or worse.

💡
Two endpoints, two purposes: /meta-agent/report gives you AI-powered recommendations — it tells you what to fix. /insights gives you dashboards data — it tells you what's happening. Together, they form a complete observability stack.
